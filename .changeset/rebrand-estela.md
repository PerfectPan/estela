The project is now Estela: install and run it as `@rivus/estela` with the `estela` command, and rename `AGENT_TRACE_*` environment variables to `ESTELA_*` (old names are no longer read). The session index cache moved to `rivus-estela`; the old `rivus-agent-trace` cache directory can be deleted.
